轻待办 v1.4.3 · Windows 便携版待办清单
================================================

界面基于 PyQt-Fluent-Widgets（Windows 11 Fluent Design，支持 Mica 材质），
数据存 SQLite，单文件 exe 免安装，常驻托盘，到点右下角提醒，
未完成任务自动延续到下一天。

一、怎么运行
------------------------------------------------
方式 A（推荐）：双击 轻待办.exe
    · 便携版，不需要安装；exe 放哪都行。
    · 首次启动会在 exe 同目录生成 data 文件夹（todo.db 就是全部数据）。

方式 B：双击 启动.bat（源码运行，需要 Python + PySide6 + PySide6-Fluent-Widgets）
    · 用于开发调试，改完代码重启即可。

二、界面速览
------------------------------------------------
左侧导航：今天 / 最近 7 天 / 全部 / 收集箱 / 已完成，下面是我的清单（可建多个、带颜色），
最下面是设置。顶部是标题、搜索框、「显示已完成」开关和快速添加框，
点开任务会从右侧滑出详情面板：日期用日历选、时间用选择器选，也可以直接打字让程序猜，
改完点「保存」生效，点「取消」丢弃。

三、核心功能
------------------------------------------------
1. 智能识别时间（打字就能排期）
   在快速添加框里直接写中文，回车即可；不写时间就默认今天 14:00。
   输入框下方会实时显示彩色胶囊：
   📅 日期时间（蓝）、🔁 重复规则（紫）、❗ 优先级（红/橙），后面跟着「回车添加」：

       十点开会                    → 今天/明天 10:00（看是否已过点）
       十一点30 见客户              → 11:30
       11点30 / 11:30 / 11：30      → 11:30
       十点半打电话                 → 10:30
       十点一刻 / 十点三刻          → 10:15 / 10:45
       下午三点 评审                → 15:00
       晚上八点 聚餐                → 20:00
       明早八点 跑步                → 明天 08:00
       今晚九点 看书                → 今天 21:00
       周五晚上8点 聚餐             → 最近的那个周五 20:00
       下周一 上午十点 例会          → 下周一 10:00
       11月20日 15:00 交付          → 11月20日 15:00
       11-20 交材料                 → 11月20日
       交周报 明天 18:00 !!         → !! 是优先级（! 低、!! 中、!!! 高）

   相对时间（从"现在"往后推）：
       1分钟后 关火                 → 现在 + 1 分钟
       5分钟后回电话                → 现在 + 5 分钟
       半小时后 取快递              → 现在 + 30 分钟
       1小时后 开会 / 一小时后 开会   → 现在 + 1 小时
       两个小时之后 出发             → 现在 + 2 小时
       3天后 复盘 / 2周后 复查       → 现在 + 3 天 / + 2 周

   循环任务（写完这一遍，以后每天/每周自动出现）：
       每天10点 吃药                → 每天 10:00
       每天 背单词                  → 每天（默认 14:00 提醒）
       每周十点 例会                → 每周一次
       每周一 十点 周会              → 每周一 10:00
       每三天十点 浇花               → 每 3 天
       每两周 大扫除                → 每 2 周
       每月15号 交房租               → 每月 15 号

   只写时间没写日期时：今天还没到就排今天，已经过了就排明天。
   只写日期不写时间时：默认按当天 14:00 处理，并且默认「到点提醒」。
   只写任务名（不写任何时间）时：直接排到今天 14:00，例如「买牛奶」→ 今天 14:00。
   循环任务如果第一次的时间已经过了，会自动从下一次开始（例如中午写「每天10点」，第一次落在明天）。

2. 详情面板（点任意任务打开）
   · 改完点底部「保存」才生效，点「取消」丢弃本次改动并关闭面板。
     有未保存内容时关窗口 / 切页面 / 换任务，会先问一句「保存 / 放弃修改」。
   · 截止日期：日历选择器，旁边有「今天 / 明天 / 清除」快捷按钮。
   · 日期时间也能手动输入：下面那行填「明天十点」「1小时后」「11-20 15:30」，
     输入时下方实时显示「识别为……」，回车（或点「套用」）就填进上面两个选择器。
     只写日期时会自动补成 14:00。
   · 时间：时/分选择器 +「全天」开关；不开全天才会参与提醒。
   · 提醒：不提醒 / 准时 / 提前 5、15、30 分钟 / 提前 1 小时 / 提前 1 天，默认「准时」。
   · 重复：不重复 / 每天 / 工作日 / 每周 / 每月 / 每 2 天 / 每 3 天 / 每 7 天 / 每 2 周；
     语义添加时识别到的规则（如「每周三」）也会显示在这里，可随时改。
   · 优先级：无 / 低 / 中 / 高（列表左侧色条同步变色）。
   · 也可「标记完成」「删除任务」。

3. 提醒通知（重点）
   · 默认走「应用内弹窗」：到点在屏幕右下角浮出提醒卡片，停留 2 分钟，
     可直接「完成」，或点「稍后 ▾」选择 10 分钟 / 30 分钟 / 1 小时 / 自定义——
     自定义里填 1~10080 分钟，点确定就按你填的时长再提醒一次。
   · 同一时刻到点的任务很多时，屏幕右下角最多只放 3 张卡片，其余排队；
     最上面那张会显示「另有 N 条提醒排队」，处理完一张（完成 / 稍后 / 关掉）就自动补上一张。
   · 任务右键菜单里也有「稍后提醒」，选项相同，适合在列表里临时推迟。
   · 卡片不经过 Windows 通知中心，所以一直开着免打扰也能照常看到。
   · 设置 → 提醒方式，可切换：应用内弹窗 / 系统通知 / 两者都要。
     系统通知会进右下角通知中心，但免打扰模式下会被静音。
   · 提醒声音默认开启，用系统提示音，免打扰拦不住。

4. 循环任务
   · 在快速添加里写「每天10点」「每周一 十点」「每三天十点」，或在详情面板的「重复」里选。
   · 勾选完成时，会自动按规则生成下一次（同标题、同清单、同提醒设置），
     右下角会提示「已生成下一次：明天 10:00」。
   · 下一次的日期如果已经过期（比如补做很久以前的每日任务），会自动推到今天或以后。
   · 想停止循环：打开任务，把「重复」改成「不重复」，或在完成前直接删掉。

5. 未完成任务自动延续
   · 每次启动、以及程序跨过 0 点时，把过期未完成的任务顺延到今天；
   · 任务上会显示「已延期 N 次 · 延期至 今天 14:00」，一眼看出顺延到了哪天；
     详情面板里还会带上原定日期，如「已自动延期 2 次（延期至 今天 14:00，原定 11-09）」。
   · 右键也能手动改日期或清除日期。

6. 托盘与开机启动
   · 关闭窗口默认最小化到托盘（设置里可改成直接退出）。
   · 托盘右键菜单：打开、新建任务、开机自动启动、退出；双击图标打开主界面。
   · 开机启动写当前用户注册表 Run 项，不需要管理员权限。

7. 快捷键
   Ctrl + N   聚焦快速添加
   Ctrl + F   聚焦搜索
   Ctrl + ,   打开设置
   Ctrl + S   保存详情面板的修改
   Esc        关闭详情面板

四、数据与备份
------------------------------------------------
· 数据库：exe 同目录 data\todo.db（SQLite，WAL 模式，与 1.1.x / 1.2.x 版本通用，无需迁移）。
· 日志：  data\app.log（出问题时看这里）。
· 备份：  整个 data 文件夹复制走即可；换电脑时把它和 exe 一起拷过去。
· 卸载：  删掉 exe 和 data 文件夹，注册表只有开机启动一项（设置里关掉即可）。

六、常见问题
------------------------------------------------
Q: 连续来好几条提醒，程序像卡住了？
A: v1.4 已修：一是卡片改为最多 3 张、其余排队，不会再堆一屏窗口；
   二是发送系统通知不再占用界面线程；三是修复了淡入动画导致卡片"透明但仍占着屏幕"的问题。

Q: 改完任务怎么没保存？
A: v1.3 起详情面板改成了显式保存：点右下角「保存」或按 Ctrl+S 才写入。
   直接关面板会弹确认，选「保存」就行。

Q: 通知不弹？
A: 设置里先确认「提醒方式」；如果选了「系统通知」而你又开着免打扰，
   系统会静音它，改成「应用内弹窗」最稳。也可以点「测试提醒」立即验证。

Q: 双击 exe 没反应？
A: 多半是已经有一个实例在跑（会弹提示）。看任务栏右下角托盘图标。

Q: 提示"Windows 已保护你的电脑"？
A: 未签名小工具常见的 SmartScreen 提示，点「更多信息」→「仍要运行」。
   也可以右键 exe → 属性 → 勾选「解除锁定」。

Q: exe 为什么这么大 / 启动要几秒？
A: Qt 运行时本身就大（已剔除 WebEngine 等无用组件，约 100MB）；
   单文件版每次启动要解压到临时目录，所以窗口出现会慢 1~3 秒。

Q: 换台电脑能用吗？
A: 能。把 exe + data 文件夹一起拷走即可，无需安装运行时。
